Kunci aplikasi

PIN membantu mencegah orang lain membuka aplikasi pada perangkat ini. Biometrik bergantung pada dukungan browser/perangkat. Ini bukan enkripsi database atau perlindungan terhadap orang yang dapat mengakses penyimpanan browser.

Backup & pemulihan

Backup mencakup akun, transaksi, tujuan, anggaran, jadwal, dan utang. Simpan file JSON di tempat pribadi yang aman; jangan unggah ke repository publik.

Sebelum memulihkan, aplikasi akan membuat backup data saat ini dan meminta konfirmasi.
